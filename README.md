# sheet-matcher

マスターの各商品が、他店の買取価格表ではどの商品名で載っているかを突合し、結果をマスター側の「突合結果_自動出力」タブに書き出します。
突合結果のタブでは価格は扱いません（商品名の対応を見つけるだけです）。価格は「価格比較」タブにまとめます（下記）。
GitHub Actions で毎日 8:00(日本時間)に実行されます。手動実行は Actions → Sheet Matcher Automation → Run workflow から行います。

## 突合の順番

1. 手動指定(下記)
2. 商品名の完全一致
3. 表記ゆれを吸収した完全一致：全角半角・半角カナ・ひらがな/カタカナ・空白・記号（「」【】・〜 など）をそろえ、「フィギュア」「プライズ」「景品」など店舗によって付いたり付かなかったりする語を除いて比べる
4. 語順ちがいの完全一致：単語を並べ替えると一致するもの（「キャラ名 作品名」と「作品名 キャラ名」など）
5. あいまい一致:類似度95%以上は自動で採用し、85〜95%は「要確認」として候補を表示
   - 両方の商品名に数字があって食い違う（Vol.1とVol.2、第1弾と第2弾など）候補は別商品として扱い、要確認にも出さない（一致方法に「一致なし (数字が違う候補のみ: …)」と表示）
   - 片方にだけ数字がある場合は、95%以上でも自動では採用せず要確認にする
   - 要確認のうち、次をすべて満たすものは「自動判定: 相互最良一致」として自動で確定する
     - 類似度90%以上で、数字が一致している
     - 2番目に近い候補より5ポイント以上高い（紛らわしい候補がない）
     - 価格表側から見ても、マスターでいちばん近いのがその商品（まだ載っていない新商品が、似た名前の旧作に結び付くのを防ぐ）
   - 価格表の1商品には、マスターの1商品だけを結び付ける。候補がすでに別のマスター商品と一致済みのとき、または候補から見てもっと近いマスター商品が他にあるときは、要確認に出さず「一致なし」にする（理由は一致方法の列に表示）
   - 自動判定のしきい値は環境変数 `AUTO_REVIEW_MIN`（既定90）・`AUTO_REVIEW_MARGIN`（既定5）で変えられる
   - 自動判定が間違っていたら、その行の手動指定で上書きできる

## 結果タブの列

マスターの列の右に、次の列が並びます。

| 列 | 内容 |
| --- | --- |
| `価格表側の商品名` | 一致が確定した価格表の商品名（要確認の行は空） |
| `一致方法` | 手動指定 / 完全一致 / 正規化による完全一致 / 語順ちがいの完全一致 / 厳格あいまい一致 / 自動判定: 相互最良一致 / 要確認 / 一致なし |
| `類似度` | あいまい一致での最高類似度 |
| `要確認_候補` | 要確認（85〜95%）の行の、最も近い候補の商品名 |
| `手動指定` | 手動で一致させる商品名（下記） |

## 価格比較タブ

突合で商品名の対応が確定した商品について、各店舗の買取価格を並べた「価格比較」タブを、実行のたびに作り直します。

| 列 | 内容 |
| --- | --- |
| `JANコード` / `商品名` | マスターの商品 |
| `ドラゴンボーン_商品名` / `ドラゴンボーン_買取価格` | メインの価格表での商品名と買取価格 |
| `千葉鑑定団_商品名` / `千葉鑑定団_買取価格` | 千葉鑑定団での商品名と買取価格 |
| `らしんばん_商品名` / `らしんばん_買取価格` | らしんばんでの商品名と買取価格 |
| `ムーラン_商品名` / `ムーラン_買取価格` | ムーランでの商品名と買取価格 |
| `最高値の店舗` / `最高値` | 買取価格がいちばん高い店舗（同額なら「・」区切り）とその価格 |

- 載るのは、1店舗以上で一致が確定した商品だけです。要確認の商品は載りません。手動指定で確定すると載るようになります。
- 価格は各価格表の「価格」を含む列から読みます。「¥」「,」「円」は取り除いて数値にします。
- このタブは毎回上書きされるので、メモなどは別のタブに書いてください。

## 他店舗の商品名を並べる

メインの価格表（Secretsの `PRICE_ID`、ドラゴンボーン）との突合に加えて、他店舗での対応する商品名を結果タブの右側に列として追加します。

| 店舗 | Secrets | 追加される列 |
| --- | --- | --- |
| 千葉鑑定団 船橋店 | `CHIBAKAN_PRICE_ID` | `千葉鑑定団_商品名` / `千葉鑑定団_一致方法` / `千葉鑑定団_要確認_候補` / `千葉鑑定団_手動指定` |
| らしんばん | `LASHINBANG_PRICE_ID` | `らしんばん_商品名` / `らしんばん_一致方法` / `らしんばん_要確認_候補` / `らしんばん_手動指定` |
| ムーラン | `MOULIN_PRICE_ID` | `ムーラン_商品名` / `ムーラン_一致方法` / `ムーラン_要確認_候補` / `ムーラン_手動指定` |

- 商品名は figure-kaitori-bot が毎朝更新しているスプレッドシート（千葉鑑定団 6:15、らしんばん 6:05）の「現在一覧」タブから読みます。状態が「削除」（買取リストから消えた商品）の行は対象外です。
- メインの価格表（ドラゴンボーン）も同じく「現在一覧」タブから読み、「削除」の行を除きます（「現在一覧」タブがなければ最初のタブを読みます）。
- ムーランは twitter-rss-discord-bot の承認ダッシュボードが書き込むシートの「sheet1」タブ（ジャンル/商品名/価格/更新日/型番・JAN）を読みます。同じ商品名が何度も載る記録形式なので、価格は「更新日」がいちばん新しい行のものを使います。
- Secrets にはスプレッドシートのIDのほか、URLを丸ごと入れても構いません。
- 突合のしかたはメインと同じです（完全一致 → 表記ゆれ吸収 → あいまい一致95%以上、85〜95%は要確認として候補の商品名を `<店舗>_要確認_候補` に表示）。
- 店舗ごとに手動指定ができます。`<店舗>_手動指定` 列（例：`千葉鑑定団_手動指定`）のプルダウンからその店舗の商品名（または「(一致させない)」）を選ぶと、次回の実行で「手動対応表_<店舗>」タブに保存され、以降も引き継がれます。使い方はメインの「手動指定」と同じです（下記）。
- プルダウンの選択肢は「価格表_商品名リスト_<店舗>」タブにあり、実行のたびに更新されます（「削除」の商品は含みません）。
- 検索サイドバーはメインの価格表（ドラゴンボーン）の「手動指定」専用です。
- Secrets が未設定の店舗は飛ばします。サービスアカウントにそのスプレッドシートの閲覧権限が必要です。

## 手動で一致させる・誤一致を取り消す

「突合結果_自動出力」タブの「手動指定」列で、プルダウンから価格表の商品名を選びます。

- 要確認の候補を採用する場合や、一致なしの行に正しい商品を指定する場合は、その商品名を選びます。
- 間違って一致している行は「(一致させない)」を選びます。
- 指定を外す場合は、セルを空にします。

選んだ内容は**次回の実行時**に「手動対応表」タブへ保存され、以降の実行でも引き継がれます(キーはJANコード、JANがない行は商品名です)。
すぐに反映したい場合は手動で実行してください。

プルダウンの選択肢は「価格表_商品名リスト」タブにあり、実行のたびに価格表から更新されます。このタブは編集しないでください。

## 検索サイドバー(おすすめ)

プルダウンの代わりに、検索して指定できるサイドバーを使えます。

### 使い方

1. メニューの「突合」→「商品を検索して指定」を選び、右側にサイドバーを開きます。
2. 「突合結果_自動出力」タブで行を選ぶと、その行の商品名から型番らしい部分が検索欄に自動で入ります。
3. 検索結果をクリックする(またはEnterキーを押す)と、その行の「手動指定」に入ります。
   - 検索では全角半角・大文字小文字・スペースや記号の違いを無視します。スペースで区切ると、すべての語を含む商品に絞り込みます。
   - 「指定後に次の行へ」にチェックを入れておくと、フィルタで表示している次の行へ自動で移ります。
   - 誤った一致を取り消すときは「一致させない」、指定を外すときは「指定を外す」を押します。

### インストール(最初に一度だけ)

1. マスター側のスプレッドシートを開き、「拡張機能」→「Apps Script」を開きます。
2. `コード.gs` の中身を、このリポジトリの [gas/Code.gs](gas/Code.gs) の内容に置き換えます。
3. 左の「ファイル」の「+」→「HTML」で `Sidebar` という名前のファイルを作り、[gas/Sidebar.html](gas/Sidebar.html) の内容を貼り付けます。
4. 保存してスプレッドシートを再読み込みすると、「突合」メニューが表示されます。初めて実行するときは、Googleアカウントでの承認を求められます。
