# sheet-matcher

マスターのスプレッドシートと買取価格表を商品名で突合し、結果をマスター側の「突合結果_自動出力」タブに書き出します。
GitHub Actions で毎日 8:00(日本時間)に実行されます。手動実行は Actions → Sheet Matcher Automation → Run workflow から行います。

## 突合の順番

1. 手動指定(下記)
2. 商品名の完全一致
3. 表記ゆれ(全角半角・スペース・記号)を吸収した完全一致
4. あいまい一致:類似度95%以上は自動で採用し、85〜95%は「要確認」として候補を表示

## 手動で一致させる・誤一致を取り消す

「突合結果_自動出力」タブの「手動指定」列で、プルダウンから価格表の商品名を選びます。

- 要確認の候補を採用する場合や、一致なしの行に正しい商品を指定する場合は、その商品名を選びます。
- 間違って一致している行は「(一致させない)」を選びます。
- 指定を外す場合は、セルを空にします。

選んだ内容は**次回の実行時**に「手動対応表」タブへ保存され、以降の実行でも引き継がれます(キーはJANコード、JANがない行は商品名です)。
すぐに反映したい場合は手動で実行してください。

プルダウンの選択肢は「価格表_商品名リスト」タブにあり、実行のたびに価格表から更新されます。このタブは編集しないでください。

## 検索サイドバー(おすすめ)

プルダウンの代わりに、検索して指定できるサイドバーを使えます。

### 使い方

1. メニューの「突合」→「商品を検索して指定」を選び、右側にサイドバーを開きます。
2. 「突合結果_自動出力」タブで行を選ぶと、その行の商品名から型番らしい部分が検索欄に自動で入ります。
3. 検索結果をクリックする(またはEnterキーを押す)と、その行の「手動指定」に入ります。
   - 検索では全角半角・大文字小文字・スペースや記号の違いを無視します。スペースで区切ると、すべての語を含む商品に絞り込みます。
   - 「指定後に次の行へ」にチェックを入れておくと、フィルタで表示している次の行へ自動で移ります。
   - 誤った一致を取り消すときは「一致させない」、指定を外すときは「指定を外す」を押します。

### インストール(最初に一度だけ)

1. マスター側のスプレッドシートを開き、「拡張機能」→「Apps Script」を開きます。
2. `コード.gs` の中身を、このリポジトリの [gas/Code.gs](gas/Code.gs) の内容に置き換えます。
3. 左の「ファイル」の「+」→「HTML」で `Sidebar` という名前のファイルを作り、[gas/Sidebar.html](gas/Sidebar.html) の内容を貼り付けます。
4. 保存してスプレッドシートを再読み込みすると、「突合」メニューが表示されます。初めて実行するときは、Googleアカウントでの承認を求められます。
