# sheet-matcher

マスターのスプレッドシートと買取価格表を商品名で突合し、結果をマスター側の「突合結果_自動出力」タブに書き出します。
GitHub Actions で毎日 8:00(日本時間)に実行されます。手動実行は Actions → Sheet Matcher Automation → Run workflow から行います。

## 突合の順番

1. 手動指定(下記)
2. 商品名の完全一致
3. 表記ゆれ(全角半角・スペース・記号)を吸収した完全一致
4. あいまい一致:類似度95%以上は自動で採用し、85〜95%は「要確認」として候補を表示

## 手動で一致させる・誤一致を取り消す

「突合結果_自動出力」タブの「手動指定」列で、プルダウンから価格表の商品名を選びます。

- 要確認の候補を採用する場合や、一致なしの行に正しい商品を指定する場合は、その商品名を選びます。
- 間違って一致している行は「(一致させない)」を選びます。
- 指定を外す場合は、セルを空にします。

選んだ内容は**次回の実行時**に「手動対応表」タブへ保存され、以降の実行でも引き継がれます(キーはJANコード、JANがない行は商品名です)。
すぐに反映したい場合は手動で実行してください。

プルダウンの選択肢は「価格表_商品名リスト」タブにあり、実行のたびに価格表から更新されます。このタブは編集しないでください。
